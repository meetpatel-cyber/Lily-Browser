# Lily Browser

Lily Browser is a focused, Chromium-based Windows desktop browser built with Electron, React, and TypeScript.

## Run locally

```powershell
npm install
npm run dev
```

## Checks

```powershell
npm run lint
npm run typecheck
npm run build
```

`npm run build` creates production renderer files in `dist/` and Electron main-process files in `dist-electron/`. Start a built copy with `npm start`.
